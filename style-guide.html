Design system — v1

An instrument panel for exam drills

Dark by default, built around one working accent (signal teal) for everything interactive, a separate reserved accent (dial gold) that only ever marks streaks, points and achievements, and a fixed correct/incorrect/marked palette for feedback that never doubles as UI chrome. Long reading — questions, options, solutions — sets in a serif; everything structural sets in a technical grotesk; every number that measures something (timers, success rates, question IDs) sets in monospace.

Rule: --signal is the only color a person can click on. --dial never appears on an interactive element — only on streak counters, points totals and achievement badges. This keeps "you earned something" visually distinct from "you can act on this."
